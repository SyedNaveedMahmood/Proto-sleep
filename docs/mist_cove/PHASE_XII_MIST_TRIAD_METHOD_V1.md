# MIST-TRIAD v1: operator-separated witness audit

This definition is committed after the resource-only two-epoch pilot and before the real scientific audit. The original classifier is frozen. This is an auditable combination of established ideas, not a claim of methodological priority.

For normalized physical epoch x, native predicted class c=argmax f(x), and fifteen binary availability atoms a, define h_x(a)=1[f_c(A_a(x))-max_{k≠c}f_k(A_a(x))>10⁻⁶]. A is the verified Phase X internal operator: local windows survive only when every overlapping physical atom is available; mean pooling retains its original denominator; seventeen global features survive only at the full mask. Neutral zero is primary, .01 is sensitivity. This feature-state operator is not a reconstructed EEG waveform. All 32,768 masks define the complete finite truth function, compiled in fixed atom order to a verified ROBDD. A signed clause (P,N) is sound iff h=1 for every completion containing P and excluding N. Subset-minimal clauses need not have minimum cardinality. The implementation additionally finds exact smallest canonical supports and exact smallest universally sufficient positive supports by a Boolean superset transform. A canonical empty-state response and a universally constant response are distinct quantities.

View B applies T to calibrated microvolt waveforms before the original frozen affine normalization and full native model. Each attempt measures target RMS change, exact preservation outside the target, absolute boundary jumps, relative squared-energy distortion and FFT-magnitude L1 distortion. Stage preservation is unknown. A changed prediction establishes sensitivity to the specified transformation, not removal of a clinical event.

Frozen whole-epoch probes are identity; 32-Hz sinusoid at .05 centered-epoch RMS; 35-Hz sinusoid at .5 RMS; .2-Hz drift at .1 RMS; a centered Gaussian transient of amplitude 3 RMS and standard deviation 10 samples; white Gaussian addition at .3 RMS; gain 1.05; and Fourier-phase randomization preserving magnitude before FP32 rounding, DC and Nyquist phase. Generator seed is 123+canonical extended-example ordinal. Independent sensitivity views use mild 32-Hz, drift and gain. They are class-blind transformations, not guaranteed independent clinical nuisances.

Each primary example additionally receives fifteen separate 200-sample linear bridge replacements. For each atom, a within-epoch TRAIN background donor is the lowest centered-RMS different atom satisfying RMS≤3 uV, ties by atom index. If none exists, record NO_ELIGIBLE_BACKGROUND; no other donor bank is searched. Replacement guards are unchanged: relative energy≤.5, spectral magnitude L1≤.5, absolute boundary jump≤5 uV. Rejects remain in the attempted denominator. No label/correctness is used to select donors. Additive probes report continuous distortions and cannot claim to pass the historical donor contract merely because they are bounded. A bridge is not a donor and is reported separately even when evaluated by the same thresholds.

View C keeps the original target c and original clauses fixed. For each declared view v, evaluate h_{v,c} over every completion. Report native prediction stability, validity of the original first active clause, any original active clause surviving, and substitution by another originally discovered active clause separately. A signed clause with negative literals is counterfactual-state-only and cannot substitute for an explanation active at the original full input. Newly discovered clauses do not count as persistence.

The deterministic TRIAD graph contains physical-atom nodes and typed clause hyperedges, alternative-clause edges, signed interfering literals, operator comparisons, and view-validity records. Joint sufficiency is explicitly conditional on the clause; it is not a universal AND-gate assertion about clinical morphology. For each compatible replacement, compare whether internal removal and physical replacement lose the original target. Disagreement is a first-class result. Non-compatible attempts cannot substantiate waveform conclusions. Confidence and neutral sensitivity annotate the graph without changing its logical claims.

Comparators use the same fixed target and table. Greedy canonical backward deletion is SIS-inspired, not the published SIS implementation. Native gradient-times-feature and absolute-gradient rankings project mean features equally to native windows, max features to their first argmax window, and window scores equally to overlapping atoms. The seventeen global features are excluded from physical rankings and reported separately. Ranked retention stops at the first canonical success; random selection matches its support size with seed 123. Report standalone head/gradient access costs, canonical success and universal-positive validity separately. The positive and signed clause summaries are bounded to four clauses and 128 short-support anchors. Their summary coverage is distinct from exact ROBDD fidelity.

Known foundations: [SIS](https://proceedings.mlr.press/v89/carter19a.html) already studies sufficient retained subsets; [Anchors](https://ojs.aaai.org/index.php/AAAI/article/view/11491) studies sufficient rules under a sampling distribution. Our finite-domain certificates are narrower than unrestricted waveform claims. [Attention MIL](https://proceedings.mlr.press/v80/ilse18a.html) already learns instance aggregation, and [SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html) already integrates rejection into classification. Neither gating nor abstention is novel here. The proposed increment is a reproducible operator-separated disagreement ledger on this exact historical model, evaluated against simpler summaries. External time-series implementations are NOT TESTED unless a fair model/operator/access-budget match is demonstrated. No patentability, first-in-world, or clinical explanation claim is made.

Cost: one structural table is 32,768 cached-head evaluations, not full-network passes. Independent views require new waveform encodings and their own complete tables. Whole-waveform probes and replacements require native full-network example forwards. Exact table verification has a separate CPU cost. Failure conditions include changed model identity, nonfinite output, incomplete tables, incompatible interventions, unavailable donors, absent active clauses, changing target class, excessive graph complexity and resource limits. Preserve all failures and denominator entries.
