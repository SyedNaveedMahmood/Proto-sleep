## Historical clinical source architectures, without invalid metric comparisons

Historical source raw_context/evidence share the TRAIN-derived waveform-bank feature framework. WaveformBank combines observed shape/band/envelope distances with a learned normalized local encoder, prototype peak/mean summaries and amplitude/summary features. Evidence uses additive nonlinear univariate feature bases. raw_context uses a64-dimensional projection, two residual conv/LayerNorm/GELU blocks and a five-class readout. Under radius0 these temporal convs are1x1 across epoch positions; the name does not imply neighboring-epoch context in the frozen source comparison. raw_context has34,197 declared/33,957 effective trainable parameters; evidence13,556. Phase III source participant F1 means .723511/.718031 concern the repeatedly used four-person development VAL, not external tests. Analytic q1 has75 parameters and much lower source F1 .477645.

The AttnSleep adapter uses its unchanged multiresolution CNN and temporal-context-encoder-style attention architecture within an epoch. Its historical source result is recorded in the public P3B report; no new fitting or presumed superiority is asserted here. Architecture names alone do not establish transfer ability.

Phase VIII's synthetic five-class codes cannot be quantitatively ranked against these clinically scored source-stage F1 values. The capacity/features/task/data differ, and no new real source run was authorized. Independent clinical event definition, montage/acquisition validity, donor physiology and cohort independence remain separate scientific gaps. The future proposal records the gates instead of assuming larger networks solve them.
