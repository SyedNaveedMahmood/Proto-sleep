This protocol precedes new Phase XIII explanation outcomes. The user authorizes the original fifteen TRAIN participants only. No new raw VAL/RESERVED/ST/SHHS/external data, other channels, EEG downloads or external transfer. Original Fpz-Cz,100Hz,3,000 calibrated samples, full physical positions, masks, night boundaries and stage mapping are preserved. The trained original raw_context123 checkpoint and the prior verified patched CPU loader retain their exact identities. No historical fitting is changed.

Primary annotation selection: canonical person/recording/night/physical-index order, stage ranks11 and12 per person, after the ten original extended-audit positions. Maximum150; missing ranks stay missing. This is stage-balanced early-epoch sampling of historically trained people, not a prevalence/generalization sample. Freeze private coordinates and canonical digest before predictions. Secondary panel: first five distinct prior-audit examples per ordered category: N1 error, N3↔N2 error, REM↔N2 error, confidence≥.9 error, correct compact active explanation, global-only-stable/local-only-changed. Skip previously chosen duplicates without outcome replacement; maximum30; report category/missing denominators separately. Fifteen duplicate presentations sample one primary case per person, stage cycling by canonical person ordinal modulo5, yielding balanced duplicate stages where available. Blind IDs are random opaque tokens; presentation order uses a separate seed13007 and hides panel membership, duplicate relationships, source identifiers, clock, stages, predictions and explanations. Optional same-recording immediate physical context is bounded and never crosses nights; default display is the original30 seconds, with no filtering or automatic gain normalization. Prefer two independently approved qualified EEG/sleep reviewers. Actual reviewer identities, credential categories, authorization scope and hashed access credentials are private. No reviewer is invented or contacted externally. Without approved qualified reviewers: prepare private packets, codebook, interface, generated controls and analysis code; genuine review, human agreement and clinical alignment are NOT TESTED. Local review requires explicit approved reviewer entries; generated demo credentials cannot unlock real EEG.

Initial pass marks observable morphology, intervals, six-state assessability, confidence, artifacts and notes, without stage or model overlays. Lock exports before model alignment. Do not adjudicate toward the model. Report each reviewer independently and an explicitly defined paired-event intersection analysis; do not turn uncertainty/not-assessable into absence. One qualified reviewer would supply exploratory observations only; primary agreement/alignment gates require two.

Degenerate whole-epoch and position controls remain flagged. Unassessable/ambiguous denominators are retained. No independent clinical annotations exist merely because the original sleep stage is known.

Annotation results cannot tune supports, thresholds or model selection.
