# Phase XIV data access protocol

Use only the exact user-supplied root held privately by the phase code. Resolve each path component through no-follow directory descriptors; accept only bounded single-link regular files. Initial inventory reads only authorized root metadata. Derive SC membership through unchanged authenticated frozen TRAIN descriptors before any source stat/open. Rebase only exact original basenames whose checksums equal both preserved historical references and the independently retrieved official manifest. Derive ST pairs from official metadata; require unique canonical subject/night prefixes, exactly44nights/22people and validated official treatment metadata.

No recursive SC enumeration, fallback paths, alternative datasets or EEG downloads. Preserve originals. Hash bounded source bytes before decoding immutable memory snapshots; file-descriptor and current-path identity/metadata checks detect substitutions. Stream calibrated native channel intervals from one recording at a time. Reject missing/duplicate labels, invalid calibration, nonfinite values, discontinuity, time mismatch or unmatched hypnograms. Quarantine individual failures; retain denominators.

Stage geometry reuses the unchanged strict TAL parser, paired fixed clocks/identifiers, MNE and pyEDFlib compatibility checks. Known corroborated ST previous-day Recordingfield exceptions preserve the paired fixed time without shifting a night. Preserve complete physical30second grids, original R&K categories,3/4→N3 and movement/unknown masks; never compress gaps or cross nights. No future/neighbor stage labels enter a model.

Only Fpz-Cz enters the historical model, using its unchanged TRAIN normalization. Other channels are proxy-analysis inputs. No ST normalization or model threshold fitting. Continuous detector segments use physicalµV with explicit native sampling and edge rules. SC1Hz envelope is never upsampled into purported raw100Hz EMG. Real data, source IDs/paths, detailed coordinates/events/predictions/conditions, fitted values, private atlas and states stay ignored/local. CI uses generated fixtures only.

The first protocol seals signal/detector/sample/analysis choices before SC proxy outcomes. After the optional SC-only context comparison and fixed checkpoint seals, a second committed package gates all ST waveform-value access. Every ST loader checks that committed seal. Any later scientific change is separately exploratory; no adaptive ST search, new cohort or further phase is authorized.
