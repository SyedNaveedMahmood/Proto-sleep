# Proposed Phase XVI study — design only

**Not authorized and not executed.** Phase XV ends with exploratory, previously exposed ST evidence. The next scientific decision should be a narrow independent test of whether exact model-dependency certificates add useful information beyond simple spectral intervals. A separate written authorization, source/data review, reviewer approval, and protocol lock would be needed before any new data or reviewer workflow begins.

## Primary question

On a genuinely independent EEG boundary with qualified blinded annotation, can a fixed MIST-WIC certificate identify independently adjudicated local events or model-error mechanisms better than an equal-duration sigma-power selector? The registered target should be one specific annotation type, channel, interval tolerance, and participant-level estimand. The existing ST spindle-like detector may remain a secondary automated comparator, never the reference standard. The historical model and neutral/operator definitions should be locked before source access.

## Minimal design

Recruit at least two approved reviewers with documented EEG/sleep-scoring credentials, blinded to method, model prediction, and one another. Use independently adjudicated event intervals with explicit no-event and uncertain-event options; measure inter-rater agreement before a consensus target is constructed. Draw a person-stratified sample from an authorized, previously unexamined boundary. Predeclare physical-epoch geometry, channel eligibility, scoring exclusions, sample size justified against participant-level uncertainty, and handling of multiple candidate events and multiple valid certificates. Resolve any overlap with earlier exposed people, nights, or model-selection data before selection.

Compare exact-positive support, sound active clauses, sigma ranking, RMS and gradient rankings, random duration-matched controls, and a time-frequency specialist baseline. Match physical seconds and account for empty/whole-epoch support. Register separate endpoints for (a) exact model faithfulness, (b) independently annotated event concordance, (c) interval-budget efficiency, (d) fixed-clause stability, and (e) the fraction of physical replacements that pass compatibility guards. A positive event-localization claim would require superiority to sigma on the **new independent** boundary, not merely to random. Incorrect model predictions must remain in the sample and be analyzed separately.

This proposal does not authorize fitting a new classifier, adapting on ST, opening any additional EEG cohort, contacting reviewers, or transferring private records. If the priority shifts to REM classifier improvement, write a distinct development protocol with a new held-out validation boundary and no use of prior ST outcomes for model selection. Keep the explanatory-method test separate from classifier training and clinical utility claims.
