# Phase X operator limitations v1

Exact masking is a prerequisite for model-dependency statements, not a physiological intervention. All observed behavior here comes from random historical-architecture mocks or explicitly privileged analytic controls. No actual trained source classifier is evaluated. Phase IX's failed clean additive, query-consistency, fixed-witness, donor and removed-information criteria remain unchanged.

Whole-epoch features create an intentional availability discontinuity: a single withheld atom suppresses all seventeen global values. A resulting class change can reflect the feature replacement policy rather than an event localized in that atom. The global-only and mixed-global/local controls require whole-epoch context; short local clinical explanations would be unsupported. Conversely, an irrelevant but faithful compact reason is still a model pathology.

The neutral-bias control and eventless input retain their class without waveform evidence. Prior-only circuits are explicitly flagged; an empty or short certificate in those controls is not localized diagnostic evidence. A certificate for the deliberately incorrect prediction remains a faithful explanation of the wrong model response. Original prediction targets are never relabeled to make explanations look correct.

Default partial mean keeps the native window denominator. This attenuates contributions as windows disappear and defines the declared operator. A valid-count mean is a different diagnostic computation: in the frozen aggregation-sensitivity control it changes the one-atom prediction from class1 to class0 (maximum logit difference .316384). That is a pooling-policy effect, not evidence that a diagnostic component was discovered. Invalid windows cannot be zero-clamped before max because valid embeddings may be negative. With no windows, the fixed neutral vector still passes through native biases/LayerNorm.

The .01 neutral sensitivity control was declared before outcomes; it is not a learned background, an inverse EEG waveform or a retrospectively chosen better result. Default-zero findings must remain primary. Globally suppressing summaries is conservative but can make almost-full support unavoidable or make masked states unlike training. Full-input identity does not certify plausibility of those states.

Analytic control detectors inspect selected real-geometry100-sample windows with generated matched templates. They intentionally use privileged fixture knowledge. Random-parameter historical source architectures have learned-layer *structure* but no trained semantic ability. Neither family estimates sleep-stage performance, clinical localization or real-source explanation utility. Generated oracle intervals are used only for scoring control alignment, not ranking or greedy selection; alignment scores for random historical models are unavailable.

Readable signed clauses are universally verified over the finite fifteen-atom domain and subset-minimal, not minimum-cardinality or a complete prime enumeration. Negative literals identify withheld conditions or repairs, not active regions in the original all-retained epoch. A class at a masked repair state is not the original decision. BDD compactness, summary coverage, support duration, original prediction quality and clinical meaning are separate endpoints.

Neutral behavior, global discontinuities, whole-epoch supports and approximate gradient attribution must be disclosed in any later human review. Head feature attribution does not reconcile nonlinear logits exactly and global attribution must not be drawn as a local waveform event. Random controls and query costs remain visible; a successful hand-engineered OR/AND/interference example is software validation only.
