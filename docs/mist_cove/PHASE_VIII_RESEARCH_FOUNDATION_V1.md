## Trust and questionable assumptions

Trustworthy engineering capabilities within tested scope: deterministic FP32 CPU training; fixed-five absent-class policy; fourteen-patch geometry; K4 original half-open intervals; exact signed accounting; sealed atomic state recovery including model/optimizer/global and batch RNG; source-role/mask/gap contracts tested on generated mocks. Engineering PASS does not establish scientific superiority. Historical CUDA correctness cannot prove new Phase VIII CUDA behavior.

Not established: automatic robust diagnostic localization, exclusive encoder/pooling/head cause, additive superiority on a successful robust shared representation, accepted-donor invariance, independent clinical event identity, clinical safety, reserved-cohort performance or external transfer. The original Phase VI weights must never be deserialized. Current hashes of old files are not historical authentication.

All 18 prospective references require Git-anchored creation proofs, exact checkpoint/seal hashes, architecture, generator/optimizer configs, source inventory and environment matching before deserialization.
