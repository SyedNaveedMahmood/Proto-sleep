# Phase X source availability operator v1

This is a new, frozen partial-observation operator for the original historical classifier. It is not a waveform reconstruction or retrained classifier. Only its all-visible state is required to reproduce native inference. No scientific policy is selected from explanation outcomes.

Input is finite FP32 normalized [N,1,3000], with the historical fixed TRAIN affine transformation assumed externally. Phase X uses only generated normalized tensors. Native ordering is scales100/200/400, mean32 then max32 per scale, summary16 and optional amplitude1, then original epoch-local RawTemporal head. No new trainable module, changed parameter, CRF or temporal context is inserted.

An atom is [200j,200(j+1)), j=0..14. For actual native unfold window w=[s,s+L), required atoms are all intervals with a nonempty intersection. Window visibility is the conjunction of those atoms. Cached encoders use complete native windows, with native local centering/RMS, GroupNorm, convolutions and embedding normalization. A cache may contain hidden-dependent values, but only fully visible embeddings reach aggregation. Cached summaries are gated before entering the head. Cache hashes bind model state, support map and tensor contents; model/cache/map tampering is rejected.

For P native windows at a scale, embedding e and visibility v, masked mean is sum(where(v,e,neutral))/P. P is fixed even with partial availability. The default neutral is the zero vector. Mean over changing valid counts is a different, unimplemented operator. Masked max excludes invalid windows with negative infinity, reduces over valid windows, and returns neutral if none are valid. Zero-imputing invalid windows before max is prohibited because it would clamp negative valid coordinates. At all-visible input, reduction values and ordering match native mean/max exactly. Local feature-availability flags mean at least one source window remains; they are not guarantees of physiological evidence.

All sixteen summary values and the amplitude value require all fifteen atoms. Any partial mask replaces them with the same fixed neutral scalar. The six500-sample segments are not independently available: the native summary normalizes the epoch and pools all six segments. Fixed amplitude_stats remain classifier buffers, never estimated from a query. Head biases and LayerNorm remain active; an empty epoch can therefore yield confident logits, which must be called prior/neutral-state behavior.

Neutral .01 is a separately declared sensitivity control using the same graph, denominator and max exclusion. It is not a plausible EEG baseline and cannot replace the primary zero policy after results. Empty, partial and full states are reported separately. Cached mean/max channels are globally pooled representations of local features, not original local features.

Outputs are [Q,N,5] logits in Wake/N1/N2/N3/REM order, with trace [Q,N,F] feature vectors, [Q,F] availability flags, per-scale window masks/counts and a full-mask flag. Full-input identity requires max absolute/relative errors within atol=rtol=1e-6; bitwise equality is recorded separately. Noninterference uses the same tolerance and inspects every retained feature path, not only a possibly cancelling final logit. All masks include exact physical availability; no hidden RMS or global bypass survives.

The adapter accepts already constructed in-memory historical models but has no file-reader API. Phase X entrypoints construct random-parameter mock instances only. Real checkpoint construction, bank retrieval, normalization access or source inference require a separate reviewed implementation and release decision. Python module isolation is not an operating-system security boundary against malicious arbitrary code; the access contract prevents accidental source resolution through supported interfaces.
