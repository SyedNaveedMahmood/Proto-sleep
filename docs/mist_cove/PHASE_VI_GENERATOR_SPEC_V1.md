# Phase VI localized generator v1

One full finite float32 [1,3000] signal is constructed at100 Hz before extracting any patch. Five artificial labels have no clinical stage meaning. All local events are200 samples, with a sin² taper including exact zero endpoints, a randomized phase, and RMS normalized to a class-free amplitude uniform[8,12]. Complete frequencies are[2,5,8,11,14]Hz; factor frequencies[3.5,6.5,9.5,12.5,15.5]Hz. These are deliberately distinguishable frequency codes for localized-information testing, not a spectrum-matched phase task or simulated clinical-event distribution.

Task single contains one complete code y. Task multiple contains two components. A class-free mode stream chooses redundant complete codes[y,y] or complementary factor codes[y,(y+1)%5] with equal probability. Two adjacent factor codes uniquely identify y on the five-code ring; either factor alone is compatible with two classes. One remaining complete witness still identifies y. Mode/type is intended diagnostic structure observable in the wave, not metadata given to a classifier. Separate redundant/complementary evaluation conditions fix the mode without changing placement or nuisance.

For each sample, streams keyed by(seed,stream_id,sample_index) independently draw class permutation, two event positions, diagnostic amplitudes/phases, background, Gaussian noise, nuisance bursts, artifact and mode. Positions sample two different sites from[100,700,1300,1900,2500] plus integer jitter[-80,80]. Both positions are drawn for both tasks. They do not depend on y, mode, amplitude or nuisance. Noise is0.5-unit independent Gaussian; slow background is a0.7-Hz sinusoid with random phase/amplitude[0,2]. Nuisance consists of two independent tapered200-sample bursts at class-free positions/frequencies[24,30,36]Hz with RMS[12,24]. A20-sample signed box artifact has independent position and peak[8,16]. Exact component arrays and complete latents are retained privately.

Competitive increases nuisance to four bursts with RMS[36,48] and artifact peak[80,100]. All four nuisance latents are drawn even when only two are rendered. Repeated uses four ordinary bursts; correlated repeats the first nuisance waveform at four independently drawn sites. Artifact uses the strong box only. Weak scales all diagnostic amplitudes by.2; partial deletes the first component of a multiple example, or retains half the single component. Removed deletes the whole diagnostic group. Eventless is all zeros, with no diagnostic intervals. Adjacent/overlap place the second event at first+200/+100, respectively. Position_shift moves each diagnostic event+200 unless that exceeds2800, then−200; complete support and baseline are retained. Nuisance_swap renders the same diagnostic component over baseline streams from seed+1. Each condition is an explicitly constructed intervention, not assumed physiologically label-preserving.

All signals are defined on one physical sample grid. No class-dependent filtering, resampling, padding, crop rejection or donor search is used. White noise and boxes need not be smooth EEG; taper continuity prevents event insertion steps but does not certify physiology. Task single redundant/complementary/adjacent/overlap names are omitted from its stress matrix where they lack meaning; no second event is fabricated. Exact recorded latents can rerender the original or override only the intended intervention.
