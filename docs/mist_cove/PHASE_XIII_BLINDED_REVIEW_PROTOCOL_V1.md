# Phase XIII blinded local review protocol

Actual qualified reviewers: none available or approved, as confirmed by the user. Actual expert-grounded physiological validity: **NOT TESTED**. The completed engineering deliverable is a local-only review workflow and private randomized panel, with generated QA tests. No model or language model impersonates a reviewer.

Coordinator tasks before review: document genuine credential category and organizational access approval; assign independent opaque reviewer handles; store only hashed tokens in a protected local registry; verify the frozen packet and codebook identities; review display settings and training instructions with the humans. Prefer at least two independent reviewers. No external EEG transfer, cloud labeling, remote hosted application or external contact is authorized.

Each reviewer first marks morphology without stages, predictions, explanation intervals, source names, participant IDs, night clock or panel selection category. All195 planned presentations are shuffled and opaque;15 duplicates are separately keyed for repeatability and never counted as independent epochs. Primary150 and enriched secondary30 remain analytically separate. The visible raw30s waveform has a time axis,50uV grid, no filtering or per-case automatic gain; zoom/pan/vertical offset and optional same-night adjacent context are logged. Context cannot be marked as if it belonged to the original0–30s epoch.

Reviewers must use uncertainty/not-assessable rather than forced negative labels when the single lead is insufficient. Record intervals, confidence, artifact/quality flags and private free text. Reviewer disagreement is not resolved toward the classifier. Independently lock each completed or partial review before any explanation overlay/alignment analysis. The lock writes a structured private export with packet identity, reviewer approval status and the complete hash chain. Edits after locking require a separately documented revision; the application denies silent changes.

QA retains completion and missingness by primary/secondary/duplicate stratum, nominal six-state agreement, chance-corrected Cohenκ where defined, per-category event matching at IoU≥.2, matched-event overlap/onset/offset differences, confidence differences and duplicate repeatability. Empty-empty event sets yield undefined event F1, not a fabricated perfect agreement. Uncertain/not-assessable cases remain explicit and do not become absence. Assess the predeclared thresholds in the scientific protocol only after genuine locked exports exist.

The HTTP service binds127.0.0.1 only, checks local Host/Origin and per-reviewer Bearer credentials, exposes only allowlisted blinded fields, blocks arbitrary file paths and master-key routes, uses no external scripts/network resources, and keeps outputs private. Real packet startup rejects an empty/unapproved reviewer registry before loading waveforms. Registry entries alone are not evidence that credentials are genuine; organizational/user approval must be independently documented. No real service is launched in this no-reviewer phase.
