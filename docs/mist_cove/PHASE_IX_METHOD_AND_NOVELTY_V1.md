## Proof assumptions and counterexamples

Full visibility retains every feature and RMS value, so calling the unchanged native decision reproduces native logits. With partial visibility, a candidate survives only if both 200-sample atoms in its 400-sample footprint survive. Local encoder normalization is patch-local; physical mean/std are fixed buffers. Therefore two waveforms agreeing on retained atoms give identical retained representations, and all discarded features/RMS are zero. Retaining an unmasked global RMS would violate the premise; the tests construct that counterexample.

A clause fixes disjoint retained P and withheld N. Exhaustive conjunction over all matching mask completions and listed views establishes finite-domain sufficiency. XOR and `(A OR B) AND NOT C` refute a monotone single-mask shortcut. Removing a literal only enlarges completions; failure of every single-literal removal implies subset-minimality, not minimum cardinality. A finite-view certificate has no guarantee on unlisted views. A negative literal is a condition of an alternative internal state, not an active reason at the original full mask. Prior-only constant responses claim no waveform support.

## Frozen operational choices (WP06)

The two-example geometry pilot measured complete 32,768-mask evaluation, compilation and readable summary in .055508s (M1) and .032473s (M2). The raw pilot initially extrapolated 1,140 tables; an accounting review before freeze includes all neutral-control and randomized-model tables, increasing the maximum to **1,272 tables**. The corrected conservative estimate is twice the slower measured table cost times 1,272, plus 600s training/evaluation overhead, below 3,600s. No pilot scientific accuracy was inspected, no new development example was evaluated, and the raw pilot receipt is retained.

Use all 60 prescribed audit examples: first two generated examples per class, restored to generation order, on each of the six task/seed cells. P0, E0 and E1 are nominated predictor sets (up to 180 predictor/example records). Three discovery views are base, independently placed added 40-uV-RMS high-frequency burst, and added 100-uV 20-sample transient. Three independent verification views use newly seeded HF/transient/HF locations/phases. Diagnostics remain identical; all geometry and nuisance draws are class independent. A zero-feature/zero-RMS operator is primary; hidden feature value .01 with zero RMS is a separately labeled baseline-sensitivity control, never an in-distribution claim.

Seed namespaces use SHA256 of `phase9/{role}/{task}/{optimization_seed}`, first four bytes interpreted little-endian. No Python hash is used. TRAIN/development/calibration/audit/verification/locked roles and their derived nuisance/sanity namespaces are inventoried in preregistration. Sizes, optimizer and endpoints equal the authoritative plan. Parent eligibility is clean development F1>=.80. Head training is clean generated TRAIN only, 150 batch16 updates. C0/C1/C2 each receive the same clean/added-nuisance TRAIN pair with equal HF/transient index strata, 300 batch16 updates, identical minibatch ordering and class-blind masks. Only full-view logits receive CE. Regularizers ramp from zero over the first 60 updates to full/query weights .5/.25. Even C0/C1 draw the same query geometry for RNG matching; only C2 incurs query forwards.

Each predictor fits one scalar temperature on its own independent 500-example calibration stream (50% original and 50% added-nuisance views) using the existing fixed 61-point log grid; these scalar calibration fits are reported separately from the 42 neural fits. E0/E1 share their already fitted calibration with circuit analysis; P0 calibration is reused by reliability evaluation. Confidence>=.60 is a reporting endpoint; margin>1e-6 defines the primary response.

Readable summaries use at most four clauses, anchored at the full mask first and then the first 128 true masks ordered by retained-atom count and integer value. Literal deletion is universally verified and subset-minimal; search is not a complete prime-implicant enumeration. The compactness endpoint records whether a discovered active clean clause can itself form a summary with <=8 retained seconds and <=8 literals; it is a bounded-search lower bound on existence. Coverage of the complete displayed collection is separately reported, so short isolated routes cannot masquerade as complete explanation coverage. Signed negative-literal clauses describe alternative internal states, not active full-input reasons.

Stability quantifiers apply to the **frozen bounded discovered clause family**. When full-input predictions agree, the fully specified all-retained clause is trivially valid; comparing unrestricted existence of arbitrary clauses would be vacuous. Report active positive-literal waveform reasons separately from signed intervention states and prior-only responses. Fixed versus substitute stability uses unchanged discovered clauses on all three new finite views, never newly optimized literals or a favorable masked replacement for a wrong full-input prediction.
