# Phase IX future source-only pilot proposal — review required, no launch

## Narrow question and justification

Can an operator-specific dependency audit expose reproducible model-retained and model-interfering regions in an already competent original-source classifier, without changing its full-input prediction? Phase IX supports exact bounded same-model analysis and compact P0 clean reasons (59/60), but not clinical interpretation, universal explanation stability, clean additive superiority or added query-consistency benefit. These mixed findings can motivate reviewing a narrow explanatory source pilot; they do not authorize it. Perfect synthetic corruption robustness is not a logical prerequisite for every source question.

Use **one** verified historical raw_context source classifier initially, selected prospectively because its documented source-development performance was adequate, not because this pilot has compared new real scores. No new real training or additive-head campaign is proposed. A later evidence comparator requires a separately reviewed extension. Historical source-VAL mean F1 .723511 (raw_context) and .718031 (evidence) concern the same four repeatedly used development participants. They are not external or unbiased independent test results.

## Dependency gate before data access

First inspect source code and dependency footprints without opening EEG or fitted banks. The historical classifier contains waveform-bank summaries, amplitude and potentially whole-epoch features. It cannot inherit the fourteen-window adapter's locality proof automatically. Every feature must declare its original physical support. A genuinely global feature must be withheld whenever its required samples are unavailable, or handled by a separately reviewed recomputation operator. An unrestricted global pathway would invalidate sparse local sufficiency. Full-visibility identity and hidden-sample noninterference must pass on generated mocks for the exact future adapter before any real source input is opened.

Verify original source checkpoint authenticity and source/config/environment lineage independently. Do not promote a newly calculated weight hash to historical proof. Missing or incompatible receipts block that artifact, not a claim that a substitute has the original identity.

## Proposed sample, frozen analysis and controls

After explicit source authorization and successful provenance/footprint review, propose at most 150 original TRAIN physical epochs: first two scored epochs per stage per each of 15 TRAIN participants, retaining original night/epoch coordinates. Missing strata remain missing; no convenient replacements chosen after model outcomes. This is a deterministic stratified model-audit sample, not a clinical prevalence estimate. Begin on TRAIN only; use of the repeatedly consulted four-person VAL would require its own declared purpose and cannot become an independent test. No subject-specific fitting, architecture selection, mask-threshold tuning or donor training is proposed.

Freeze one native checkpoint, operator/neutral definition, physical atom vocabulary, margin threshold, target as original model prediction, bounded clause policy, sample identities, discovery/verification operators and all analysis endpoints before prediction exports. Include correct and wrong original decisions. Compare native ranking, SIS-inspired canonical sufficient subsets, positive-only universally verified clauses and signed MIST-WIC. Retain summary coverage, retained physical duration, negative-literal semantics, compactness, baseline sensitivity and query cost. A short irrelevant model reason is a model pathology, not a validated clinical event.

Primary engineering endpoints: exact unchanged full-input prediction and verified hidden-sample withholding, complete finite response fidelity on the bounded vocabulary, sound subset-minimal certificates and truthful partial-summary coverage. Scientific endpoints: model-dependency coverage/compactness, active versus counterfactual-state explanations, fixed versus substitute support on separately specified views, original-label accuracy/error strata, localization only where independent event annotations exist, and raw/calibrated confidence if a permitted TRAIN calibration role is defined. Do not use the pilot to tune a stage classifier or optimize four-person VAL scores.

## Source contract and privacy

Preserve the original **15 TRAIN / 4 development VAL / 55 RESERVED** split and all frozen fingerprints. Original calibrated Fpz-Cz EEG, 100 Hz, 3,000 samples per 30-second physical epoch are mandatory. Preserve complete physical positions, unscored masks, recording/night gaps and original offsets. Use only previously verified TRAIN normalization; no fitting on VAL or any test role. No trimmed legacy NPZ substitution. All raw/annotation/descriptor hashes must be checked only for explicitly authorized development roles, with role rejection before data-bearing access. RESERVED, Sleep-Telemetry, SHHS, independent cohorts and target adaptation remain excluded.

Keep all real waveforms, detailed predictions, annotations, model states, fitted banks and explanation traces ignored locally. Public results must be aggregate and deidentified. Initially use model-retained/model-interfering terminology; no spindle, K-complex, slow-wave, REM biomarker or artifact labels without independent blinded event definitions and review. Internal withholding is not a plausible reconstructed EEG. Real waveform replacement and inpainting are outside this first pilot.

## Resource and authorization gates

Phase IX's 339.225 measured scientific CPU seconds apply to the compact synthetic model, not the stronger source architecture. Propose a policy ceiling of one GPU-hour for a small audit only after an independently authorized two-example resource pilot measures the actual dependency graph and full finite enumeration. That is a proposed ceiling, not an invented feasibility estimate. The approved final sample size and query budget must be frozen before source analysis; if the projection exceeds the reviewed ceiling, reduce scope prospectively or defer. GPU use requires an idle appropriate device and new bounded correctness/resume checks. Phase IX CUDA was blocked and supplies no new CUDA validation.

Separate human decisions are required for: original development artifact access; source dependency adapter and privacy review; measured pilot budget; final frozen source-audit launch; and public aggregate release. Any change to the scientific question, real training, VAL fitting, donor bank, reserved evaluation or external cohort requires further authorization. This document is a proposal only; **zero real EEG was accessed in Phase IX**, and no Phase X starts automatically.
