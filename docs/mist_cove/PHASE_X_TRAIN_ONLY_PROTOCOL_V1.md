## Frozen analysis and interpretation rules

Target is the original full-input predicted class, including wrong predictions. Response is target margin strictly>1e-6 under the declared operator. Report ties/unsupported full responses rather than changing target or tolerance. All masks use physical atoms; each candidate requires its complete actual receptive-field support. Report global-summary removal separately from local-window suppression. Full original scores and correct/wrong counts use only approved TRAIN labels; no claim of calibrated masked confidence follows from full-view calibration.

Use terms **model-retained support**, **model-interfering context**, **model-substitutable support**, **jointly required retained context**, and **operator-sensitive region**. Never automatically label an interval as a spindle, K-complex, slow wave, REM event, artifact or clinically causal evidence. Those concepts require independent definitions/annotations and separately approved evaluation. Correctness of a dependency certificate is not medical correctness.

An active reason at the original all-retained epoch has no negative literals. Signed clauses with withheld literals describe other internal states or possible repairs; they are not active original waveform events. A certificate explaining a wrong class remains a faithful explanation of that error. Empty/prior-only reasons claim no waveform evidence. If the whole epoch is required, report30 seconds directly. If global removal changes class artificially, disclose the operator limitation rather than annotating an event.

Native-head gradient attribution uses internal features and is approximate; greedy/random baselines use canonical queries; signed/positive clauses require universal completions. State each method's actual query/cache cost, full-table reuse, support size, exact fidelity domain and bounded coverage. Clinical interval precision is unavailable without independently annotated events; never substitute generated oracle locations for real annotation evidence. A real perturbation/stability/donor study requires its own operator definitions and authorization; Phase X mock clauses do not establish source witness stability.

Finish the future authorized scope with negative outcomes retained, safe aggregate review and a human decision. No automatic training, RESERVED/external evaluation, expansion to all TRAIN data or Phase XI follows.
