# Phase XI-B through XII-A scientific decision

The mission produced an authenticated original-model investigation, exhaustive real-source response analysis, an implemented operator-separated TRIAD method and the complete nine-fit prospective comparison. The original classifier is now inspectable through a verified adapter. The proposed reliability model is **not promoted**: all three M2 seeds failed the registered incremental gate. Stop for scientific review; no subsequent phase begins automatically.

**Q1. Can the original checkpoint be loaded and verified safely?** Yes, in the implemented bounded, authenticated, patched-CPU workflow. Original bytes, named state, configuration, selected run and root-bound TRAIN fitting metadata pass. P3A creation-chain independence, full training replay and independent signer/time attestation remain unestablished. This conclusion concerns the selected authenticated artifact, not arbitrary serialized objects.

**Q2. Does the adapter preserve the trained classifier?** Yes. Generated trained-state feature/logit identity and84 noninterference comparisons passed; real native/full logits were bitwise equal on all750 audited epochs. All1,350 real response tables reconstructed exactly. Clinical validity does not follow from computational identity.

**Q3. What fails on original EEG?** N1 recognition, some N3/N2 and REM/N2 distinctions, confidence under error, sensitivity to nuisance, and persistence of the same explanatory clause. Full TRAIN accuracy.9477 coexists with N1 recall.5044; reused development-VAL N1 recall is.3267. Stage-balanced early-epoch accuracy is much lower than whole-grid accuracy. Signal-quality associations and within-recording transitions are described without inferring clinical ambiguity or artifact truth.

**Q4. How much is global versus local?** Internal global suppression changes31/150 primary predictions; global-only features preserve37/150, and local-only preserve119/150. Twenty-three require the full30 seconds for universal positive support. These different questions do not give a single causal percentage of global physiology. The operator suppresses all whole-epoch features under partial availability.

**Q5. Are there compact verifiable witnesses?** Exact positive search finds100/150 nonempty supports≤8 seconds; the bounded display exposes86/150 compact active clauses. Signed counterfactual coverage is larger but is not full-input support. Median graph size475 nodes and incomplete readable summaries138/150 limit human usability. Twenty-seven targets also win with all features internally withheld.

**Q6. Do compact explanations identify correctness?** No supported separation:58/99 correct and28/51 incorrect predictions have compact active summaries. The participant-level rate difference interval crosses zero. A wrong classifier decision can be explained exactly.

**Q7. What does TRIAD add?** It exposes distinctions that a single ranking/retention score omits:147/150 predictions survive mild HF while only109/150 original first active clauses remain universally valid; seven cases substitute another originally active clause. It also records2/33 compatible structural-versus-bridge disagreements and widespread neutral sensitivity. This is demonstrated additional information, not proven superiority to published time-series explainers or improved clinical decisions. Bounded signed summaries actually cover fewer true masks on average than the positive-only heuristic.

**Q8. Are constrained waveform conclusions reliable?** Only narrowly. Thirty-three of2,250 bridges pass the unchanged guards; six lose the target. All2,250 background requests fail the predefined low-RMS eligibility rule before replacement. Compatible effects are sparse and still do not establish physiological intervention validity. No true spindle/K-complex/slow-wave removal was tested.

**Q9. Does the original model recognize missing information?** Inadequately. Complete internal withholding still produces mean confidence.7389. Temperature fitting did not improve the internal TRAIN development calibration. Confidence rejection can reduce observed development errors by sacrificing coverage, but it supplies no safety guarantee and no independent generalization evidence.

**Q10. Was a new architecture justified?** A bounded test was justified by the frozen local-noise accuracy drop. Deployment or an unrestricted architecture expansion is not justified. The measured mechanism generated a falsifiable M2-versus-M1 experiment, and that experiment failed.

**Q11. Did the reliability model improve?** Not under the registered gate. Mean M2−M1 changes were−.006115 clean and−.001400 local-HF Macro-F1. Every seed failed; seed456 also exceeded the allowed clean penalty. Exact signed contribution accounting passed, while all models remained weak classifiers with near-collapsed N1 recall. Limited capacity/optimization is unresolved; no extra fits were used to rescue the result.

**Q12. What remains unsupported?** Physiological localization, causal EEG event explanations, true stage preservation under perturbation, real-world robustness, independent clinical/external validity, architecture superiority, novel-method priority and patentability. External time-series baseline superiority was not tested. No independent event annotations were available. Nine small models and four reused VAL participants cannot establish population-level conclusions.

**Q13. What next?** First, independently review a small prospectively selected set of correct/incorrect original-model epochs with separately authorized expert event/artifact annotations, explicitly separating scorer uncertainty from model error and testing whether internal support corresponds to identifiable morphology. Second, if model development continues, preregister a fixed local/global capacity-and-optimization adequacy study before adding another regularizer, with a genuinely independent selection/evaluation boundary and a newly approved compute budget. The current nine-fit allocation is exhausted; no final all-TRAIN fit was reserved. Neither proposal is executed here.
