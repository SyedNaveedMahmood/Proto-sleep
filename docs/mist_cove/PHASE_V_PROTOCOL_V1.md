## V0 and V1 — historical audit

Verify the original Phase IV synthetic config, model, generator, preregistration, public result and CUDA-addendum hashes without loading checkpoints or rerunning the 54 fits. A separately instrumented replay must equal the historical generator bitwise for tested conditions. It records complete latent draws: class/code/phase-bank identity, diagnostic amplitudes/intervals/count, nuisance identities/amplitudes/intervals, slow-background amplitude/phase, full noise seed/sample stream offset, overlap/cropping geometry and generation order. Class permutation and all label-free random consumption are separated in the audit explanation; no hidden branch on class identity is introduced.

Seeds 123/456/789; historical substitutable/complementary tasks. Train draw seed=seed+10000 with condition train; evaluation seed=seed+100000 clean and competitive; pairing seed=seed+200000. Train 1000 balanced samples, evaluate 2000 independently generated balanced samples/condition. These are new diagnostics, not a reproduction of the old 300-example/100-evaluation benchmark. Exact label-swap pairs retain every nuisance latent and replace only class-coded diagnostic factors; reverse pairs retain diagnostics and replace nuisance. Oracle erasure uses stored latent components, never labels in learned features.

For each task/seed fit unchanged conventional M1 on original inputs (A), unchanged M1_phase (B), and unchanged M1 on coherent whole-epoch zero-phase input (C). All use 300 AdamW updates, batch16, lr .001/wd .0001/clip5, FP32/deterministic, final step only, identical minibatch indices and initial conventional weights. No evaluation selection or hyperparameter sweep. D uses restricted shallow classifiers without time-domain phase reconstruction; E evaluates oracle diagnostic removal with nuisance held fixed. Probes use the same 300 minibatches and optimizer recipe, TRAIN-only feature standardization with minimum std .01, and a fixed 32-unit GELU hidden layer. Capacity differences and feature dimensions are reported; do not call them parameter matched. The permutation probe permutes TRAIN labels only with an independent fixed stream; evaluation retains true labels. Include a fixed balanced cyclic-random prediction chance reference with uniform .2 probabilities, rather than calling constant-class Macro-F1 the chance value.

Probe inputs: isolated/scaled length-200 diagnostic magnitudes; zero-embedded diagnostic-only epoch magnitudes; complete epoch and original fourteen flattened patch magnitudes; amplitude summaries; absolute envelope/boundary/patch extrema; event positions/counts; true nuisance-only magnitude; nuisance latent factors; permuted-label patch magnitude. No class/code identifier, diagnostic phase or label enters restricted features. Record log magnitudes at all bins (DC retained), not only five bands. Report class-conditioned mean differences of power, bands, RMS/variance, envelopes, patch means/extrema, edges, geometry and nuisance factors. Use balanced accuracy, fixed-five F1, recall/confusion, NLL/Brier/ECE, collapse and confidence.

Historical spectral leakage is supported if any prespecified magnitude-only probe has 99% Wilson accuracy lower bound >.30 in every seed of a task. Nuisance leakage uses the same rule for position/nuisance features. Restricted near-chance equivalence requires the entire 99% Wilson interval within [.15,.25] in each seed; failure is INCONCLUSIVE unless the leakage rule passes. Do not average away failures or claim universal information absence. These are finite-decoder descriptive repeated-generator criteria, not multiplicity-corrected population inference.

Quantify magnitude preservation, patch-overlap consistency, circular even symmetry, full/boundary magnitude differences and exact power cross-term reconciliation. B exceeding A/C by .10 F1 in all seeds supports an accessibility/optimization advantage conditional on these controls, not an exclusive artifact cause. D succeeding falsifies a unique temporal-morphology reading regardless of B-C. Hold nuisance fixed in class-swap pairs, and diagnostic fixed in reverse pairs. Report prediction changes, agreement and probability shifts, not merely correctness.

## V2 and V3 — separately versioned diagnostic code

If the historical benchmark fails phase-isolation, the already fixed harmonic-relative-phase-v1 generator constructs one continuous physical [1,3000] signal. No patch is reconstructed during generation. Noise, diagnostic/global phase and amplitude, independent 13-Hz nuisance, sample order and artifact position use explicitly class-free RNG draws. Counterfactual class swaps reuse complete nuisance and θ/A. Whole-epoch support [0,3000) and all fourteen candidate intervals are traceable. End-to-start discontinuity is not a clinical continuity claim; interior signal is smooth except independent white noise and the separately declared artifact.

Clean has 0.5-µV Gaussian noise, A uniform[8,12] and independent nuisance amplitude[4,8]. Competitive uses nuisance amplitude40. Erased retains nuisance/noise and removes both harmonics. Artifact adds an independent 20-sample ±80 burst at uniform[100,2780). Primary validity/learnability conditions are clean and competitive; erased tests loss and confidence, artifact is a prespecified stress diagnostic. No generator parameter is changed after inspecting outcomes.

V2 correctness requires exact paired nuisance equality, finite geometry, reproducibility, valid intervals, equal noiseless candidate/epoch magnitudes to relative tolerance1e-5, and analytic harmonic-phase oracle accuracy≥.99 on clean/competitive each seed. Oracle is an explicit diagnostic decoder, not a learned model or clinical event detector. V2 failure stops all V3/V4 fits.

V3 fits the same A/B/C and new restricted probes with the same exposure as V1. No new encoder. PASS requires in EVERY seed: original M1 clean F1≥.80, competitive F1≥.70; all true-label magnitude/amplitude/position/nuisance probes' clean/competitive 99% accuracy intervals contained in [.15,.25]; erased M1 confidence≤.35; original versus coherent zero-phase clean F1 gap≥.10; diagnostic-swap prediction-change fraction≥.80 and nuisance-swap prediction-agreement≥.80. Also report patchwise phase removal; no requirement that it preserve labels. These compound criteria are demanding by design. If any clause fails, stop confirmatory V4, preserve every fit and report insufficient optimization/capacity as unresolved when appropriate. No extra steps, thresholds or alternate seed selection.

V4, only after V3 PASS: reset/refit conventional/additive/event-disabled heads for 150 updates on each seed's identical frozen final original M1 encoder and identical TRAIN exposure; verify encoder digests. Native score, full individual/group intervention, fixed path, reselection, donor spread and tiny-noise stability remain distinct. Use oracle diagnostic subtraction, bridge and independent nuisance donors, never claim physiological validity. Require M2 F1≥M1−.03, localization gain≥.10 and donor spread≤.25 in all seeds for organization superiority. Since this task carries diagnostic information throughout the epoch, localization precision may be saturated and an advantage non-identifiable. Report that limitation rather than manufacturing focal truth. No organization claim follows from exact accounting alone.

## Resources, uncertainty and stopping

Check the budget between operations and bound the command externally; write incomplete/failure status atomically. Three seeds are optimization/generator repetitions. 99% Wilson accuracy bounds are per independent balanced evaluation draw, not participant intervals. Paired diagnostics resample independent nuisance-realization groups (500 bootstrap replicates), never count five class swaps as independent groups. Report bounds and all failed clauses.

Run full CPU regression and existing CUDA regression. Refuse concurrent compute jobs before allocating. Do not interrupt any other GPU process. No silent CPU fallback. Publish safe synthetic aggregate JSON/CSV, hashes, commands and reports; keep weights, latent traces, checkpoints and logs ignored.
