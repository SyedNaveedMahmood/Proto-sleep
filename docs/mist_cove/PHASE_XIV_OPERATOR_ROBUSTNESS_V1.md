# Phase XIV: response-operator and physical robustness

The original P3B model uses 15 disjoint two-second waveform availability atoms and closure over 169 historical overlapping windows and 209 features. Hidden samples cannot reach local, RMS or global paths. All-retained identity is exact. On 150 SC and 219 ST primary audit cases, every finite table and signed clause is verified. Internal response correctness is a model-specific mathematical result; it does not imply physiological cause.

| Registered perturbation | SC stable prediction / same original clause | ST stable prediction / same original clause |
|---|---:|---:|
| Mild 32 Hz HF, 0.05 RMS | 142/150 / 119/150 | 208/219 / 142/219 |
| Slow 0.2 Hz drift, 0.10 RMS | 149/150 / 141/150 | 216/219 / 182/219 |
| Gain 1.05 | 148/150 / 148/150 | 212/219 / 208/219 |

Clause substitution is tracked separately: a different original active clause recovers five SC mild-HF and one ST mild-HF cases. A stable prediction alone is not a stable explanation. Changing the neutral hidden state from exactly zero to 0.01 changes 127/150 SC and 206/219 ST response tables. The positive minimum changes in 34 SC and 45 ST cases. The finite result is therefore operator dependent.

Every physical attempt retains unaffected samples exactly, but historical waveform compatibility guards reject most requests. SC has 42 compatible bridge replacements among 2,250 requests and zero attempted background replacements among 2,250. ST has 500 compatible bridges among 3,285 requests and 94 compatible backgrounds among 3,285. Structural versus waveform-class-loss comparisons disagree in 10 SC bridges, 102 ST bridges and seven ST backgrounds. Denominators are compatible comparisons for those disagreement counts; guard rejection is reported separately. For compatible ST bridges, 37 lose the target model response; none of the 94 compatible ST backgrounds do. The operator graph does not establish event removal or clinical label preservation. Human event and clinical deletion validations remain **NOT TESTED**.

The six-fit context comparison adds two whole-neighbor variables to the fifteen center atoms. All 60 context tables reconstruct 131,072 states exactly, with 7,864,350 cached queries. C1 uses future as well as past context, so it is offline. C1 changes the dependency structure: 14/15 C1 selected cases use a neighbor; 0/15 C0 cases do. C1 fails the predefined SC transition-improvement gate in all three seeds, so added dependency complexity is not justified by this experiment.
