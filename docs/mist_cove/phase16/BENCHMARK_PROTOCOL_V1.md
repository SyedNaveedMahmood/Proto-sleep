# Phase XVI event benchmark protocol, version 1

**Freeze status:** methods and exclusions specified before any DREAMS archive or annotation outcome was read. The actual source inventory, participant allocation, and final sample count cannot be frozen while source access is blocked. This document is therefore a conditional protocol, not a claim of a completed preregistration or independent result.

The provisional primary target is expert-marked spindle intervals on the original central EEG channel. Each excerpt remains bound to its original recording and participant. The confirmatory reference, if feasible, is the intersection of genuine expert-1 and expert-2 coverage, with expert 1 as the primary operational label and expert 2, union and matched-event intersection as sensitivity definitions. “Union” and “intersection” are operational definitions, not an adjudicated clinical consensus. Reviewer agreement is reported first. The known expert-1 1,000-second cutoff is a maximum until actual files prove a narrower coverage; expert 2 is absent for excerpts 7–8. No unscored region is a negative.

All intervals are half-open `[start, end)` in seconds relative to physical excerpt time zero. The source timestamp and duration are preserved as decimal values. Sample conversion uses nearest integer with half-up ties at the **native** rate; sample coordinates are derived, not replacement annotations. An event crossing the verified physical duration or scorer-coverage boundary is excluded with reason, never truncated to improve overlap. A 30-second binary presence label is positive if a verified event intersects a fully covered window; it is negative only if the whole window is covered and no event intersects. Partial coverage yields unknown. No stage labels are used for inclusion or detector tuning.

The fixed primary one-to-one matching policy maximizes the number of event pairs with IoU ≥ 0.20, then total IoU. Sensitivity thresholds are IoU ≥ 0.10 and 0.30. Report event precision, recall, F1, mean matched IoU, false positives per **covered** minute, unmatched events, coverage minutes, and cases that cannot be assessed. Empty reference and empty detection sets are reported separately, with undefined F1 rather than manufactured perfection. Duration and onset/offset error require genuine event extents; if a scorer supplied points or conventionally assigned one-second durations, report that limitation explicitly.

The baseline sequence is fixed YASA Phase XIV spindle detector with its recorded version and parameters where central-channel/native-rate contracts permit, then equal-duration sigma power, relative sigma power, RMS, local amplitude, and a fixed time-frequency control. Any detector that requires stage labels must be marked ineligible for the stage-blind primary analysis. No threshold is selected from held-out expert labels. The primary uncertainty unit is original participant; excerpts from the same person stay grouped. If owner files cannot establish person mapping and cross-archive overlap, training and participant-bootstrap conclusions are blocked. A small fixed detector sensitivity table may be reported as sensitivity, never promoted to registered primary after seeing outcomes.

No new central-channel event model is authorized by this conditional protocol alone. Before fitting one, record the actual participant-disjoint folds, complete label-coverage denominator, TRAIN-only normalization, architecture identity, two fixed seeds at most, at most sixteen fits and 24,000 total optimizer updates, and the chosen held-out assessment boundary. The complete 15-atom response table, if used, costs 32,768 masks per example and counts against 25,000,000 new cached-head queries. Full-input identity, hidden-sample noninterference, model-state sealing and all-row circuit verification must precede physiological comparison. A positive alignment claim must beat equal-duration sigma with participant-level uncertainty; formal clause soundness alone cannot satisfy it.

Resource ceilings are inherited from the Phase XVI request: 18,000 scientific CPU seconds, at most two optional GPU hours, zero historical P3B/ST updates and zero new SC VAL, SC RESERVED or SHHS reads. The current phase has zero new fits, optimizer updates, cached-head explanation queries and external EEG reads. Failed or ineligible tasks remain in the ledger.
