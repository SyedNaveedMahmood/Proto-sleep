# Phase XIII novelty, morphology sources and comparison limits

Interpretability, local/global EEG features, attention, confidence scores and reliability gates already have substantial prior art. This study demonstrates a bounded internal-dependency audit and controlled optimization comparison. It does not establish first priority, patentability, clinical usefulness or superiority to modern EEG systems.

| Primary source reviewed | Established idea | Implication here |
|---|---|---|
| [Carter et al., AISTATS2019](https://arxiv.org/abs/1810.03805) | Minimal sufficient subsets under missing-feature semantics | Retention alone is established; distinguish canonical retention from universal signed clauses |
| [Crabbé and van der Schaar, ICML2021](https://proceedings.mlr.press/v139/crabbe21a.html) | Dynamic perturbation masks for time-series predictions | Waveform-region attribution is established; replacement and withholding semantics need explicit separation |
| [Ilse et al., ICML2018](https://proceedings.mlr.press/v80/ilse18a.html) | Learned attention aggregation of instance embeddings | Weighted local evidence is established; scalar gates do not by themselves constitute a scientific innovation |
| [CAttSleepNet,2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9104971/) | Local-sequence attention plus inter-epoch recurrent context for single-channel sleep staging | Segment weighting and local/global context already exist; this family intentionally tests a narrower one-epoch architecture |
| [SleepTransformer,2021/2022](https://arxiv.org/abs/2105.11043) | Epoch/sequence attention visualization and entropy-based uncertainty | Neither explanation display nor entropy is novel here; attention visualization differs from exhaustive availability verification |
| [SERF, CIKM2022](https://arxiv.org/abs/2209.11174) | Map learned embeddings to scoring-related features and simple rules | Physiological interpretation is an established research goal; our absence of independent event labels is an unresolved gap |
| [DistillSleep,2025](https://academic.oup.com/sleep/article/48/12/zsaf240/8239690) | Intra-epoch wavelength, inter-epoch attention and confidence tools | Modern interpretable EEG alternatives exist; indexed publisher excerpts only, direct full text access failed |
| [Attentive Adversarial Network, MLHC2020](https://proceedings.mlr.press/v126/nasiri20a.html) | Attention and adversarial approaches to heterogeneous sleep recordings | Robustness research predates these gates; bounded class-blind signal sensitivity is much narrower than cross-domain validation |
| [SelectiveNet, ICML2019](https://proceedings.mlr.press/v97/geifman19a.html) | Joint prediction and rejection | Confidence/reliability are distinct from explanation validity; no rejection policy is being validated here |

The potential technical differentiator is a fully specified physical-atom closure, withholding all dependent pathways, exact finite nonmonotone response reconstruction, sound signed subcubes, and unchanged-clause persistence distinguished from substitution, together with guarded operator comparisons. Boolean decision diagrams, sufficient subsets, signed rules and nuisance tests are individually established. A combination is only a candidate contribution; neither this focused search nor arithmetic correctness proves novelty. No direct modern-baseline retraining or clinical study was authorized or performed in this phase.

The new width comparison changes only width, preserving local receptive fields, global inputs, data, loss, exposure and seed streams. R1 versus R0 is paired within width/seed/horizon. R0 stores frozen inactive gate weights for identity parity; report active and stored counts separately. The historical P3B has different features, normalization, architecture, fit exposure and source-person overlap, so it is a reference audit, not a matched capacity baseline. The original mild whole-epoch32Hz probe differs from the new local35Hz probe; compare nuisance behavior within each family. All new models use a reused TRAIN10/5 allocation, not an untouched population sample. We report every seed and view and apply the frozen all-seed gates; exploratory comparisons do not select a winner.

The morphology codebook is an operational draft for future qualified review. Primary spindle sources [Wendt2015](https://pmc.ncbi.nlm.nih.gov/articles/PMC4426257/), [Warby2014](https://sleepcohort.wisc.edu/wp-content/uploads/sites/1452/2020/10/Warby2014.pdf) and [single-channel scorer study2024](https://www.frontiersin.org/journals/sleep/articles/10.3389/frsle.2024.1427540/full) motivate explicit uncertainty and independent event agreement. Indexed primary excerpts were available; access to some full texts was restricted. The [AASM manual resource](https://aasm.org/clinical-resources/scoring-manual/) was inspected as a normative reference, not reproduced. The Japanese society's large PSG chart could not be retrieved by the browser. Thus numeric morphology conventions are draft candidates requiring reviewer confirmation; they are not validated lead-specific diagnostic thresholds. No reviewer or language model has supplied clinical annotations. Additional channels, physiological diagnoses and human agreement remain untested.

Sources were checked2026-10-22. This is a focused primary-source review, not an exhaustive systematic priority search. Source access limitations are explicit; no medical recommendation is inferred from these research comparisons.
