# Phase XIV automated event methods

All event locations are **automated proxies**, not independently human-confirmed annotations. Primary detectors are stage-blind and receive no model predictions or hypnogram. No pretrained weights are used. A separate pinned YASA0.6.5 environment preserves the patched PyTorch2.10CPU historical-model environment unchanged. Full package versions are sealed before ST. Thresholds are fixed in the initial committed config; no candidate is selected by explanation agreement.

The published implementation is [YASA](https://yasa-sleep.org/), with its [spindle detector](https://yasa-sleep.org/generated/yasa.spindles_detect.html) and [slow-wave detector](https://yasa-sleep.org/generated/yasa.sw_detect.html). The currently hosted docs describe a newer version; actual execution pins0.6.5and its source/API. Spindles use12–15Hz, broad1–30Hz, durations.5–2s and default relative-power/correlation/RMS criteria. A preregistered stricter RMS alternative is retained separately. Slow waves use the published default.3–1.5Hz/duration/amplitude rules, with one explicitly relaxed amplitude alternative. No default amplitude convention is assumed validated for these bipolar leads. Onset, offset, duration, frequency, amplitude, detector statistics, channel and status remain private with source references.

Primary method sources are [Lacourse et al., A7 spindle detection](https://pmc.ncbi.nlm.nih.gov/articles/PMC6415669/), [Massimini et al., slow oscillations](https://www.jneurosci.org/content/jneuro/24/31/6862.full.pdf) and [Carrier et al., slow-wave changes](https://doi.org/10.1111/j.1460-9568.2010.07543.x). YASA is an inspired published implementation, not an exact claim to reproduce every original paper experiment. A7's evaluation cohort and human reference do not validate these particular outputs. Carrier's direct full text was not accessible; YASA documents the methodological lineage. Training-data overlap of learned event detectors is avoided by using deterministic algorithms, but signal/montage and threshold limitations remain.

Continuous detection uses30minute cores plus30second physical padding on each side. Candidate midpoint assigns each event to one core; only actual recording edges lose10seconds of detector eligibility. Events may span epoch/core boundaries and retain absolute source coordinates; epochs are not independently filtered for detection. No padding crosses recording or night boundaries. YASA's own FIR filters are retained; explicit EOG/EMG filters are fourth-order zero-phase Butterworth with generated frequency-response checks. Core-local RMS/background estimates are algorithm-defined and frozen, not classifier normalization or ST parameter tuning. Nonevent, amplitude-ineligible, failed and flat/unassessable outcomes must not become expert absence labels.

Independent deterministic controls include2second sigma/delta/alpha/theta/HF spectral-ratio intervals, local RMS and peak-to-peak/amplitude summaries. EOG uses.3–5Hz excursions above50µV with explicit duration bounds; a single horizontal derivation does not diagnose REM. SC EMG uses its native1Hz envelope, while ST uses native100Hz waveform and a20–45Hz derived1second RMS. Fixed low/high amplitude proxies are descriptive; they do not establish REM atonia. Flats,100µVsteps,500µVextremes, physical-bound clipping and channel disagreement remain possible artifacts, not expert labels. Native marker changes are descriptive. [PhysioNet's official documentation](https://www.physionet.org/content/sleep-edfx/1.0.0/) explains marker baseline/error semantics; actual sample rate is taken from each header, not from its generic1Hz description.

Generated controls produce spindle-like and slow-wave-like positives and no such detections on a flat signal. A flat fixture initially exposed undefined coherence; the failed attempt is recorded and missing coherence is now null, never invented zero. All source thresholds stayed unchanged. A later validation-only input guard rejects label/prediction arrays before ST execution; the executed SC source identity is separately recorded. This hardening does not alter valid detector inputs or thresholds.

Alignment uses sample-resolution interval unions,0/.1/.25second tolerances and nonempty exact-positive supports. Random/position controls match selected2second-atom budgets; RMS, relevant spectral bands and native gradient ranking match the same budget. Greedy retention reports its own budget and cannot win an unmatched-width claim. Shifting event intervals10seconds and fixed next-epoch Pz-Oz permutation within a recording supply false-agreement controls. Whole-epoch/empty supports and detector failures retain separate denominators. Cross-channel event agreement uses one-to-one greedy maximum eligible IoU≥.2; two correlated EEG channels are not two independent experts. Proxy agreement, internal certificates and guarded physical sensitivity remain distinct scientific views.

Known explanation foundations include [SIS](https://arxiv.org/abs/1810.03805), [time-series dynamic masks](https://proceedings.mlr.press/v139/crabbe21a.html), Boolean decision diagrams and sufficient/contrastive rules. Local aggregation and temporal context are also established. This phase tests an incremental auditable combination against matched controls; it does not claim to invent detectors, first priority, clinical validity or SOTA. Human event accuracy remains NOT TESTED.
