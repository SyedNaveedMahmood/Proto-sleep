# Phase XV locked exploratory analysis protocol

The binding scientific rules are the exact bytes of `configs/mist_cove_phase15_v1.json`. They are committed before new Phase XV ST research queries. The lock prevents outcome-driven panel or threshold changes; it does not create a new prospective ST test. Any necessary engineering correction is recorded separately with old/new code identities and unchanged scientific settings.

The full scored ST grid is used to reproduce the REM row and describe REM→Wake, REM→N1, REM→N2, rare REM→N3 and correct REM, with N2 and non-REM-error controls. Physical 30-second positions, all unscored gaps and recording/night boundaries remain explicit. Previously cached logits, signal features and continuous-stage-blind detector events are used only after exact Phase XIV identity checks. One approved ST waveform pass supplies new spectral entropy, short-window variation and EOG/EMG descriptions; no stage label or prediction enters detector inputs. Associations are stratified by participant, scored REM class and condition; cause, scorer error and clinical disorder are not inferred.

The representative E1 panel is SHA256-selected one scored epoch per stage/person/night with seed 15011, at most 220, without model outcomes or detector results. The E2 panel is the E1 subset eligible under the existing frozen Pz-Oz spindle-like proxy, without using explanation support. The E3 forensic panel is capped at 40 per six fixed outcome categories (240 maximum), with balanced person/night rotation and no replacement of missing strata. All coordinates stay private and are frozen before new explanation comparisons. Cross-panel overlap is recorded and cached operations are shared.

Exact minimum supports, signed certificates, greedy retention, gradients, sigma, RMS, delta and random/position controls have declared information access. Ranking methods select the same physical two-second atom count as exact support; greedy uses and reports its own budget. Event overlap uses the same post-selection intervals for every method. Empty, whole-epoch and unassessable cases have explicit denominators. The original failed Phase XIV sigma gate is unchanged. Phase XV effect sizes are exploratory with 1,000 participant bootstrap draws, seed 15015; nights, cases, views and masks are not independent people.

The source-frozen warning rules are top-two logit margin below 0.5, predictive entropy above 1.1 nats, and local/global argmax disagreement. High confidence means at least 0.9. No threshold, calibration or deployment rule is fitted on ST. Prespecified negative controls include ten-second proxy shifts, within-recording permutations, matched random intervals, wrong masks, invalid clauses, wrong cache identity, channel rate and coordinate faults. Failure of a biological alignment comparison cannot be converted into a pass by redefining its target.

The ceiling is zero new neural fits, zero optimizer updates, 18,000 scientific CPU wall seconds and 38,000,000 new attempted-plus-successful cached-head queries. A resource pilot precedes any new complete response-table campaign. Results continue independently when an exploratory endpoint is sparse. Missing human expert annotation leaves physiological and clinical localization **NOT TESTED**. Phase XVI is a proposal only.
