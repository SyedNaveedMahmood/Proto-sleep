# Phase XI-C original-source diagnostic protocol v1

This protocol is frozen before new EEG predictions. Authorization comes from the user's Phase XI-B through XII-A task, whose text digest is recorded in the config. Required entry gates are authenticated original bytes, default-only restricted loading in patched PyTorch, exact state/configuration identity, original TRAIN-fit metadata linkage, and actual trained-adapter generated-input correctness. The selected model is original P3B raw_context seed 123, best epoch 28; no alternative checkpoint or source can be substituted.

Data: original calibrated Fpz-Cz, 100 Hz, 3,000 samples, complete physical 30-second epochs, original night boundaries, scored/unscored positions and R&K3/4-to-N3 mapping. Only frozen original 15 TRAIN and four development-VAL roles are permitted. Use the unchanged load_development implementation through authenticated in-memory descriptor transport; role rejection occurs before descriptor access. EDF bytes are hash-verified into a sealed RAM file before decoder access. No directory discovery. No new historical normalization fit.

## Samples, endpoints and budgets

Freeze both primary and extended private coordinate lists before predictions: canonical recording ID/night order, then original physical index, first two scored epochs of each stage per TRAIN participant (maximum 150), and first ten per stage (maximum 750, inclusive of primary). Missing strata remain missing. The two-epoch pilot uses the first two distinct primary-list coordinates, before model outputs. Selection is stage-balanced and not a prevalence sample.

Primary estimands: native prediction correctness, exact response fidelity, minimum support found, active and signed summary coverage, prior-only fraction, global-feature reliance, compactness versus correctness, operator sensitivity and independent-view validity. Explain the original predicted class with target margin >1e-6. Freeze neutral 0 and sensitivity .01, fixed native pooling denominator, all-or-neutral whole-epoch features and the original fifteen 200-sample atoms. Original correctness tolerance is atol=rtol=1e-6, with bitwise equality reported independently. Compact means at most eight retained seconds and eight signed literals; displayed clause extraction is bounded and does not establish globally shortest explanations. Exact exhaustive positive-support minima can be reported separately when calculated over all canonical masks.

Primary 150 and extended 750 receive one complete 32,768-mask zero-neutral table each. Primary cases additionally receive .01-neutral tables and three fixed class-blind independent nuisance views: mild 32-Hz addition (0.05 times centered epoch RMS), low-frequency drift (0.10 RMS at 0.2 Hz) and mild gain (1.05). Use independent seeds derived from fixed example ordinal, never labels/predictions. View changes are sensitivity operators, not guaranteed stage-preserving physiological channels. Re-test unchanged original clauses against all completions; distinguish prediction stability, fixed-clause validity and substitution by another originally discovered clause. State-cache and table reuse are counted explicitly.

Maximum total availability/head queries: 50,000,000. Maximum full-network example forwards: 250,000. Maximum measured scientific CPU wall: 7,200 seconds, excluding dependency installation, tests and report rendering. Two CPU threads; no GPU is required for source audit. The two-example pilot must project primary and extended cost before expansion; if an extension cannot fit, record NOT RUN and preserve the primary result. No incomplete example is replaced. Training has its separate maximum nine-fit/10-GPU-hour contract; count CPU training against the remaining CPU ceiling if used. GPU occupancy is checked before any optional CUDA allocation; occupied devices are left alone.

Broader original TRAIN predictions cover all 79,984 physical positions, with 79,025 scored expected. These are in-sample diagnostics for a historically TRAIN-fitted model. Preserve physical gaps. Record stage confusion/F1/recall, participant/night variability, fixed-five and observed-class balanced accuracy, NLL/Brier/ECE15, confidence>=.9 errors, and worst-participant performance. Signal-quality associations use amplitude, RMS, DC, low/high-frequency energy, flatness and transients; they do not establish cause or artifact truth. No clinical interval localization metric exists without independent event annotations.

Development-VAL is embargoed until new-model GO/NO-GO and any candidate/loss/threshold definitions are frozen. Its full 21,796 physical/21,789 scored positions are a descriptive historical reproduction check. It cannot select a new architecture, calibration or perturbation threshold and is not independent validation. Fit temperature/abstention rules only within TRAIN participant partitions, using fixed 10-fit/5-development allocation from a seed-123 permutation of sorted original TRAIN participants. Preserve exposure limitations of the historical model, which already saw all fifteen people.

## TRIAD and controls

Compare structural availability, waveform intervention and independent-view stability separately. Native gradient-times-feature ranking, absolute gradient ranking, greedy retained selection, verified positive clauses, signed WIC and size-matched random masks share exact response tables where valid. Report their standalone queries and gradient access. A named external explainer is NOT TESTED unless its published implementation can be fairly reproduced. Identity transformations, time-independent random rankings and generated OR/AND/XOR/interference controls are mandatory.

Waveform probes include controlled gain, mild/strong frequency-limited addition, drift, transient, broadband addition, phase-sensitive modification and local bridge/background replacement. For every attempt measure target change, exact nontarget preservation, boundary jump changes, relative energy change and spectral magnitude distortion. Historical donor thresholds remain energy<=.5, magnitude-L1<=.5 and boundary<=5 uV; background candidates retain the historical centered-RMS<=3 uV rule. Report their acceptance and rejected denominators. New additive nuisance probes report distortion continuously and make no historical-donor-pass claim.

Public outputs contain aggregate counts, deidentified distributions and reviewed digest/status receipts. Private coordinates, input caches, complete predictions, tables, clauses and any waveform plots remain ignored. Bootstrap original participants, retaining paired views/masks within each unit; fixed seed 123, 1,000 resamples, descriptive intervals. Four VAL participants cannot support a precise population claim. Report missingness and worst-participant effects without identifying individuals.

## Conditional model-development decision

After TRAIN analyses, decide whether a specific observed mechanism supports one compact local/global reliability model. A low historical N1 score alone is insufficient. Require a measured dependency or nuisance mechanism and an explicit control that could falsify the proposed remedy. Freeze one candidate and M0/M1/M2 controls before any training or VAL inspection. M2 must differ substantively from the failed Phase IX masked-query consistency objective. If no mechanism is identified, record NO-GO and complete independent analysis. If resource/security gates prevent training, record BLOCKED and finish the design/comparator/test package without inventing results.
