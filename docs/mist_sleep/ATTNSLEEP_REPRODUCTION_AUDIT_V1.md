# AttnSleep reference decision: `ADAPTED_REFERENCE_ONLY`

The repository implementation has two 1D convolution branches, AFR squeeze/excitation residual processing, a temporal context encoder with convolutional attention, and a five-class head. The generated one-batch probe reduced stage loss from 1.78 to 0.002 in 20 GPU updates with finite gradients. This rules out an inability to optimize a simple synthetic batch. It does not establish reproduction of the publication's training conditions.

The official [AttnSleep repository](https://github.com/emadeldeen24/AttnSleep) describes its K-fold data preparation, original training script and cross-dataset benchmarks. Phase M0 instead uses original untrimmed physical SC TRAIN epochs, a fixed 10/5 participant split, fit-only normalization, paired bounded augmentation, class-balanced draws, AdamW and a fixed 1,200-update checkpoint. The single 30-second epoch contains all A0 input context; no neighboring epoch is added. The architecture has 522,805 trainable parameters here versus 41,429 in M0–M3. A0 is therefore an adapted architecture reference.

The historical P3B result (0.312650 participant Macro-F1 averaged over seeds on four SC source-VAL people) had N3/REM collapse in the selected seed-789 model. Plausible contributors include training exposure, source preprocessing and checkpoint selection; the available aggregate evidence does not identify one causal failure. The 20-update synthetic test and the new matched training are concrete checks, but neither retroactively proves why that historical run underperformed. M2–M0, not M2–A0, determines whether MPI itself adds value.
